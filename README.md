# Image Pixel Manipulation Tool

A simple Python-based tool for image encryption and decryption using pixel manipulation techniques. This project demonstrates basic cryptographic concepts applied to image processing.

## 📝 Overview
This tool allows users to encrypt images by performing mathematical operations on every pixel or by swapping pixel values. The original image can be fully restored using the same key during the decryption process.

## 🚀 Features
- **Pixel Value Transformation:** Modify RGB values using basic arithmetic operations.
- **Pixel Swapping:** Randomize pixel positions to scramble the image.
- **Symmetric Decryption:** Easy restoration using the original encryption key.
- **Format Support:** Works with common formats like JPG and PNG via the Pillow library.
